03 / Guidelines

Personalidade não é bagunça.

Regras simples preservam reconhecimento, leitura e velocidade de implementação.

✓

Faça

Use tokens semânticos. Reserve o acento para hierarquia, ação e feedback.

×

Evite

Não misture a geometria Pickle com a Admin no mesmo contexto de produto.

⌁

Movimento

120–320ms, com propósito e alternativa para movimento reduzido.

⌗

Ícones

Lucide, traço de 2px, sempre acompanhando — nunca substituindo — rótulos críticos.
