# Card

Agrupa informação relacionada. Só o torne interativo quando todo o card tiver um único destino; caso contrário, use links e botões internos explícitos.

```html
<article class="sd-card sd-card--interactive">
  <p class="sd-card__eyebrow">Projeto / ativo</p>
  <h3 class="sd-card__title">Central de comando</h3>
  <p>Resumo curto e útil.</p>
</article>
```

Evite cards dentro de cards, sombras em todas as camadas e blocos com mais de duas ações de mesmo peso.
