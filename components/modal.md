# Modal

Use para uma decisão curta que precisa interromper o fluxo. Conteúdo extenso, navegação ou formulários complexos merecem uma página ou drawer.

Use o elemento nativo `<dialog class="sd-modal">`, um título ligado por `aria-labelledby`, fechamento explícito e retorno de foco ao gatilho. Escape deve fechar quando não houver risco de perda silenciosa. A ação segura fica antes da ação principal; destrutiva exige rótulo específico.
