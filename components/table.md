# Table

Use para comparar registros por colunas. Cabeçalhos descrevem os dados; ordenação informa estado com `aria-sort`. A tabela deve ter nome acessível e ficar em `.sd-table-wrap` para rolagem horizontal segura.

Alinhe números à direita na implementação, mantenha ações na última coluna e ofereça uma alternativa responsiva quando as colunas críticas não couberem. Não transforme cada célula em badge.
