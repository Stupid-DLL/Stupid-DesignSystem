# Toast

Feedback breve de ação assíncrona. Use `role="status"` para sucesso/informação e `role="alert"` somente quando exigir atenção imediata. Sucesso pode sumir após 4–6 s; erro persiste até leitura/fechamento.

Nunca use toast como única confirmação de ação destrutiva ou para conteúdo que precise ser recuperado depois.
