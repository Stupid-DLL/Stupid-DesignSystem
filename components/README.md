# Componentes

Todos os componentes consomem tokens semânticos, preservam a mesma anatomia nas famílias Pickle e Admin e suportam teclado, foco visível e movimento reduzido.

| Componente | Arquivo | Papel |
| --- | --- | --- |
| Button | [button.md](button.md) | Disparar ações |
| Input | [input.md](input.md) | Receber texto e dados |
| Card | [card.md](card.md) | Agrupar conteúdo relacionado |
| Modal | [modal.md](modal.md) | Decisão bloqueante contextual |
| Dropdown | [dropdown.md](dropdown.md) | Ações secundárias compactas |
| Table | [table.md](table.md) | Comparar dados estruturados |
| Toast | [toast.md](toast.md) | Feedback assíncrono breve |
| Badge | [badge.md](badge.md) | Estado ou categoria curta |
| Skeleton | [skeleton.md](skeleton.md) | Reserva de layout durante carga |

Estados obrigatórios quando aplicáveis: `default`, `hover`, `active`, `focus-visible`, `disabled`, `loading`, `error`.
