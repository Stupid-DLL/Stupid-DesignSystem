# Grid e layout

Grid de 12 colunas, gutter de 16px no mobile e 24px a partir de `md`. Conteúdo padrão limita-se a 76rem.

| Breakpoint | Valor | Intenção |
| --- | ---: | --- |
| xs | 30rem | Telefones largos |
| sm | 40rem | Layout compacto |
| md | 48rem | Tablet/painel básico |
| lg | 64rem | Desktop |
| xl | 80rem | Desktop amplo |
| 2xl | 96rem | Telas operacionais |

Use containers e queries pelo conteúdo, não por modelo de dispositivo. Em Admin, priorize densidade e comparação; em Pickle, respiro e composição editorial.
